# Shopifya — Modern E-Commerce Website

**Tagline:** *Discover More. Shop Better.*  
A complete, responsive E-Commerce Shopping Platform built using **HTML5**, **CSS3**, and a clean, beginner-friendly **JavaScript** file (`script.js`) for a 1st-year B.Tech Web Development college project.

---

## Project Introduction

**Shopifya** is a modern multi-section online store inspired by leading e-commerce platforms. Designed with a bold **Dark Navy**, **Royal Blue**, and **Orange** color palette on crisp white and light grey surfaces, it showcases product categories, 12 featured products, promotional flash deals, new arrivals, best sellers, customer reviews, newsletter signup, an About Us section, and customer support contact form.

---

## Problem Statement

First-time online shoppers and students often face cluttered e-commerce pages that are hard to navigate on mobile screens and lack clear pricing, discount visibility, and intuitive category browsing.

---

## Project Objectives

- Build a complete, structured e-commerce interface using semantic **HTML5** and custom **CSS3** (without Bootstrap or CSS frameworks).
- Implement responsive layouts using **Flexbox**, **CSS Grid**, and **CSS Media Queries** across desktop, laptop, tablet, and mobile screens.
- Provide clean interactive UI features (live product search, wishlist heart toggle, and slide-over shopping cart drawer) via a separate beginner-friendly `script.js` file without pretending real payments occur.

---

## Technologies Used

- **HTML5** (Semantic layout structure and accessible form validation)
- **CSS3** (Custom properties, Flexbox, CSS Grid, hover transitions, responsive breakpoints)
- **JavaScript (Vanilla ES6)** in `script.js` (Cart drawer state, wishlist counter, live product search filter, demo form toast notifications)
- **Google Fonts** (`Plus Jakarta Sans` & `Inter`)
- **Font Awesome 6 Free** (Icons via CDN)

---

## Website Features

- **Sticky Navigation Bar**: Brand logo, 7 section links, search bar toggle, wishlist badge, slide-over shopping cart drawer, and login modal.
- **Hero Banner**: Headline *"Everything You Love, All in One Place."*, promo discount badge, dual CTAs, and custom shopping showcase illustration.
- **8 Product Categories**: Electronics, Fashion, Men's Clothing, Women's Clothing, Shoes, Watches, Home & Living, and Accessories.
- **12 Featured Products**: Wireless Headphones, Smart Watch, Running Shoes, Casual T-Shirt, Laptop, Smartphone, Backpack, Sunglasses, Bluetooth Speaker, Digital Watch, Fashion Handbag, and Sneakers with discounted prices, badges, ratings, wishlist hearts, and Add to Cart buttons.
- **Special Offers, New Arrivals & Best Sellers**: Dedicated promotional banners, 4 fresh arrivals, and 4 top-selling favorites.
- **Why Shop With Us & Customer Reviews**: 6 trust feature cards and 4 verified customer testimonials.
- **Newsletter, About Us, Contact & 4-Column Footer**: Complete customer care form, store overview, and responsive footer.

## How to Run Using VS Code Live Server

1. Open **Visual Studio Code**.
2. Click **File > Open Folder...** and choose `c:\Users\HP\OneDrive\Desktop\web development\Shopifya`.
3. Install the **Live Server** extension by *Ritwick Dey* from the Extensions tab (`Ctrl + Shift + X`).
4. Open `index.html` and click **Go Live** in the bottom-right corner (or right-click `index.html` > **Open with Live Server**).
5. Your browser will launch automatically at `http://127.0.0.1:5500/index.html`.
